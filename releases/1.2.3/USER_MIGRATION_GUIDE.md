# 1.2.3 升级操作说明

## 升级前

1. 在旧版“设置 → 加密备份与恢复”生成并再次校验 `.dhwb` 加密备份。
2. 将备份保存在本人控制的本机位置，并妥善保存密码。

【隐私】备份包含患者敏感资料，不要发送或上传给任何外部地址。

## 升级后

1. 首次打开会在本机升级至 schema 13，并保留升级前快照。
2. 首页进入“病历书写提醒”，逐格对照院内正式病历核对既往节点。
3. 红、橙、蓝或紫色格表示本机尚未确认；点击后变为绿色，绿色再次点击可撤销。
4. “随POD”表示该次POD病历同时满足出院前一天／当天的病历要求。

未点击仅表示本机尚未确认，不代表院内病历一定缺失。查房文字不会自动完成正式病历提醒。
