# 1.2.3 本地发布准备

状态：本地源码修改完成，尚未上传或发布。

## 主要变更

- 首页新增病历书写提醒入口，展示待处理、严重逾期、今日及出院窗口数量。
- 新增独立点击式表格，患者为行，POD节点与出院病历为列；点击即可确认完成，再次点击可撤销。
- 规则覆盖 POD1、2、3，以及 POD6 起每3天；实际出院后停止生成新POD节点。
- 计划或实际出院前一天至当天形成出院病历窗口；与POD节点重合时只计一次并同步完成。
- 逾期1—2天显示橙色、3—6天红色、7天及以上深红色高亮。
- 病历完成标记与查房文字完全分离，仅保存日期节点和确认时间，不保存病历正文。
- 数据 schema 升级至13，覆盖备份恢复、撤销建档恢复、住院号更正与升级前本机快照。
