# 代寰宇的工作板 1.1.11

本目录对应 1.1.11 本地上传准备版本。`source.tar.gz` 仅包含小程序源码与发布配置，不包含患者资料、本地存储、加密备份或私有项目配置。

## 本次 UI 修订

- 首页移除与顶部导航重复的“患者总览／设置”入口，直接进入在院患者总览。
- 出院患者卡片只保留“出”标记，避免与“出院”状态重复。
- 主刀保持主视觉信息，一助作为次级信息展示；患者列表、首页和详情页层级一致。
- 患者列表的“编辑资料”改为卡片底部操作行，不再与日期或过敏提示重叠。
- 有过敏史的患者在患者列表中也使用醒目警示样式；未记录时仍不显示。
- 详情页把出院操作置于关键日期下方，显示计划出院日期并明确“今天出院”；点击后仍须在弹窗中确认。
- 患者姓名默认显示全名；用户可在首页、患者库、详情和查房页主动切换脱敏显示。
- 主刀与一助采用相同尺寸；患者类型与病程状态固定置于卡片顶部标签区，长姓名不再挤乱对齐。

## 数据与兼容

- 预设出院日期到当天（GMT+8）或已过期时，患者会在应用下次打开或读取数据时自动切换为出院。
- 既有患者资料、待办、查房、引流记录及备份导入兼容逻辑均保留。
