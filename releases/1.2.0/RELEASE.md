# 1.2.0 本地发布准备

状态：本地上传包已准备，尚未上传或发布。

## 主要变更

- 新增统一的紧凑型确认弹窗与底部编辑面板，页面不再直接叠加 `wx.showModal`。
- 弹窗主按钮可见高度为 62rpx，点击热区为 76rpx；保持紧凑，不使用 88rpx 大色块按钮。
- 编辑面板按键盘高度限制可用区域，正文独立滚动，标题与底部操作栏固定可见。
- 删除输入框失焦时强制下移面板的逻辑，查房长文本改为固定高度内部滚动。
- 引流量异常改为在当前编辑面板内二次核对，不再叠加系统确认窗。
- 首页协作文本、患者出院/归档/撤销、入院导入、设置项移除以及备份恢复统一使用明确的确认状态。
- 增加操作中锁定，降低连续点击造成重复保存、重复恢复或重复写入的风险。
- 首页标题按设备胶囊位置自动避让；脱敏与设置入口移出右上胶囊区，改为紧凑、完整可点击的独立入口。
- 数据 schema 保持 10，未改变患者资料、事实状态、查房内容或备份结构。
