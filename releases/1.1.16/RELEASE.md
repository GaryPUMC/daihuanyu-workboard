# 代寰宇的工作板 1.1.16

本目录对应 1.1.16 本地上传准备版本。`source.tar.gz` 仅包含小程序源码、测试与公开发布配置，不包含患者资料、本地存储、加密备份或私有项目配置。

## 发布重点

- 数据 schema 升级至 8：计划出院日期与实际出院日期分离；旧版 `dischargeDate` 按既有状态兼容迁移。
- 手术日期仅作日程提示，临床状态以明确流程阶段为准；详情页恢复流程、术中交接、术后状态与记录入口。
- 批量入院导入改为原子写入，避免中途失败造成部分保存；路径规则防重复。
- 引流 POD 空行可持久化；备份恢复后可从设置页回退至恢复前自动快照。
- 关键任务、出院通知和流程配置强化确认与影响提示。
