# 代寰宇的工作板 1.1.21

本目录对应 1.1.21 本地上传准备版本。`source.tar.gz` 仅包含小程序源码、测试与公开发布配置，不包含患者资料、本地存储、加密备份或私有项目配置。

## 发布重点

- 支持未来入院日期及“待入院”状态，预入院患者与在院患者、常规待办隔离。
- 床位对未入院患者不再必填，未分配时明确显示“待分配”。
- 病房为科室级配置；单病房科室保持简洁，多病房科室在 AI 导入、手工录入和编辑时均要求明确选择。
- 多病房科室统一以“病房 · 床号”显示，覆盖首页、患者库、患者详情、查房与待办；旧记录不作猜测性迁移。
- 待入院患者仅显示在“待入院”区域，不再重复进入出院或出院后待归档区域。
- 数据 schema 升级为 v9，兼容既有本地数据与备份导入。
