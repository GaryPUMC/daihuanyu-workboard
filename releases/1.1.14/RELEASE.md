# 代寰宇的工作板 1.1.14

本目录对应 1.1.14 本地上传准备版本。`source.tar.gz` 仅包含小程序源码与发布配置，不包含患者资料、本地存储、加密备份或私有项目配置。

## 发布重点

- 本地数据 schema 升级至 5，兼容既有引流记录并转换为 POD 记录方式。
- 实际出院日期可人工选择，仍保持日期有效性和先后顺序校验。
- 引流使用“POD 行 × 引流列”表格；记录“拔”后仍可更正拔管当天及此前记录，拔管后的 POD 不可新增记录。
- 输入弹窗改为直接跟随键盘高度位移，减少键盘升起时的重复动画与卡顿。
- 旧版引流迁移兼容 `present` 等在位状态、旧设备类型及关联/数值字段；仅明确已拔除的旧引流保持锁定。
- 首页排序固定为日间、国疗、普通，同类按床号；查房入口前置，术后患者以紫色 POD 标签提示。
- 查房页仅优先显示在位引流患者，方便按 POD 汇报。
- AI 入院导入兼容中文引号，提示词明确要求使用英文半角 JSON 引号。
