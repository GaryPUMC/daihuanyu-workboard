# 1.1.14 更新日志

- 首页患者按“日间 → 国疗 → 普通”排序，同类按床号排列。
- 出院登记支持选择实际出院日期，适用于周末等延后补录；仍拦截日期无效或先后逆序。
- 编辑诊断、过敏史、术式和日期时，不再要求填写更正理由。
- 引流记录改为 POD 表格：可添加引流列和 POD 行，填写引流量或“拔”；拔管后该引流不可继续记录。
- 既有引流记录会兼容转换为 POD 记录，原有本地数据不丢失。
- 入院资料 JSON 整理格式明确要求英文半角双引号，导入解析同时兼容中文引号。
- 首页将查房入口前置，并增加紫色 POD 标签；查房页聚焦在位引流患者，直观显示 POD 与最近引流量。
- 拔管后可更正拔管当天及此前的历史引流记录；拔管后的 POD 不可新增记录，兼顾更正灵活性与防误输。
- 优化输入弹窗随键盘升起的动画：去除重复缓动，改为跟随键盘高度的 GPU 位移，减少卡顿感。
- 完善旧版引流兼容：可识别旧在位状态、设备类型、引流关联和数值字段；旧在位引流可继续补录，明确已拔除的旧记录仍锁定。
