# 1.1.0 更新日志

- 整形轮转后界面精简为患者总览。
- 患者卡片与详情新增过敏史、出院日期，并突出主刀、一助与关键日期。
- 保留引流和引流量、正式术式确认、拍照预约／PPT／放疗会诊文本复制及完成状态。
- 所有日期统一按 GMT+8 北京时间；修复两字姓名脱敏。
- 旧版本本地数据与备份导入兼容，迁移前在本机保留快照。
- 恢复患者详情中的查房记录与待办栏，便于记录主刀交代并完成勾选。
- 协作文本入口对整形患者始终显示；拍照、PPT、放疗复制后均保留完成状态。
- 有过敏史时在总览和详情以醒目警示样式显示。
- 首页恢复当前待办板；协作文本不再按手术日期拦截，仅在预览中提示核对。
- 首页患者卡片补回诊断简称。
- 未记录过敏史时不显示过敏信息行。
- 按出院日期和手术日期自动评估并展示术前、手术、术后、出院状态，不改动既有流程记录。
- 引流可在手术当天及术后添加、记录引流量，不再依赖手动推进流程阶段。
- 首页和患者库将出院患者单列并标记“出”；当日入院标记“新”；日间同日出入院仍计入在院。
- 加入基于已授权 v3 备份结构的脱敏导入 demo 与自动测试；源码不包含任何真实患者资料。
- 设置页新增“脱敏 Demo 模式”：进入时本机快照当前数据，显示 10 位合成患者；可一键恢复原数据。
