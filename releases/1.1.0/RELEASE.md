# 代寰宇的工作板 1.1.0

本目录对应 1.1.0 本地版本。`source.tar.gz` 仅包含小程序源码与发布配置，不包含患者资料、本地存储、加密备份或私有项目配置。

## 主要更新

- 首页收敛为患者总览；卡片明确展示主刀、一助、入院／手术／出院日期与过敏史。
- 患者详情保留正式术式确认、拍照／PPT／放疗协作文本及完成状态、引流与引流量记录，以及查房和主刀交代待办；常规流程与模板不再显示。
- 新增过敏史和出院日期，旧版患者记录自动补为空值，不删除任何旧字段或旧记录。
- 所有日历日期按 GMT+8 北京时间计算；两字姓名脱敏显示为“姓*”。
- 首页展示当前待办；协作文本的手术日期仅作预览提示，不阻止复制。
- 患者状态会按出院日期和手术日期自动显示为术前、手术、术后或出院，旧流程字段保持不变。
- 引流可从手术当天开始添加和记录；出院患者单列，“新”标记当天入院，日间同日出入院仍归在在院列表。
- 患者详情在日期信息栏提供“标记出院”；确认后自动写入当日（GMT+8）出院日期并切换为出院状态。预设出院日期到当天时，应用下次打开或读取数据会自动切换为出院，既有资料和待办均保留。
- 测试目录包含 v3 脱敏导入 demo，记录规模与本地备份结构一致，但不含任何真实患者资料。
