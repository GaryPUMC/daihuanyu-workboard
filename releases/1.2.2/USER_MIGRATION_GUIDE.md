# 1.2.2 升级操作说明

## 升级前

1. 在旧版小程序进入“设置 → 加密备份与恢复”。
2. 输入至少 8 位备份密码，点击“生成并校验”。
3. 将生成的 `.dhwb` 文件保存在本人控制的本机位置，并妥善保存密码。
4. 点击“校验备份”，重新选择该文件，确认出现“备份加密校验通过”。

【隐私】备份包含患者敏感资料。不要把备份或密码发送、上传给任何外部地址。

## 升级后

1. 更新到 1.2.2 后首次打开小程序，旧术前核查会在当前设备自动转换，无需逐位患者操作。
2. 进入“设置 → 加密备份与恢复”，确认出现“旧版术前核查已转换”。
3. 抽查三类患者：已经确认正式术式、尚未确认正式术式、既往完成拍照协作。
4. 患者详情中的“术前核查”应只显示“与主刀确认正式术式”。

## 异常处理

- 如果患者数量、正式术式或拍照完成状态异常，立即停止新增或修改记录。
- 保留升级前的 `.dhwb` 加密备份，不要反复恢复到同一异常版本。
- 等待修正版后，在“设置 → 加密备份与恢复”选择该备份恢复；恢复前仍会再次校验并在本机保留当前数据快照。

迁移、校验和恢复均在本机进行，本小程序不会自动发送数据。
