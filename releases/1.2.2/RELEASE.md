# 1.2.2 本地发布准备

状态：本地源码修改完成，尚未上传或发布。

## 主要变更

- 患者详情的“术前核查”仅保留“与主刀确认正式术式”，移除同意书、术前检查、病史签字和术前拍照四个通用勾选项。
- 正式术式名称与确认时间成为唯一当前状态，不再使用通用 `preopChecks`。
- 数据 schema 升级至 12。v11 及更早数据在本机自动迁移：旧拍照完成转换为协作事件，其余旧核查转换为只读历史事件。
- 无正式术式名称的旧确认勾选不会被推断为已确认，需用户重新向主刀核实并填写。
- 迁移覆盖在院、归档和撤销建档回收站，重复规范化不会生成重复事件；覆盖当前数据前自动保留原始本机快照。
- 设置页显示迁移结果，并增加升级前备份提醒；完整操作见 `USER_MIGRATION_GUIDE.md`。

## 用户升级步骤

1. 升级前在旧版“设置 → 加密备份与恢复”生成并再次校验 `.dhwb` 加密备份。
2. 更新后首次打开自动迁移，无需逐个患者操作。
3. 在设置页确认迁移提示，并抽查已确认、未确认及既往拍照患者。
4. 如发现异常，停止新增记录并保留升级前备份，等待修正版后恢复。
