# 代寰宇的工作板 1.1.20

本目录对应 1.1.20 本地上传准备版本。`source.tar.gz` 仅包含小程序源码、测试与公开发布配置，不包含患者资料、本地存储、加密备份或私有项目配置。

## 发布重点

- 出院必须通过“确认出院”录入实际出院日期；流程圆点不能绕过日期确认直接进入出院。
- 实际出院日期不得晚于当天；误出院可填写原因撤回至术后，归档后仍保持只读。
- 日间患者的入院、手术、计划出院与实际出院日期统一为入院当天；建档、编辑与出院界面均显示为同日且不可分别修改。
- 已确认出院患者移出在院列表和首页普通任务池，仍保留在“出院后待归档”区域处理关键项与一助通知。
- 旧记录若阶段已到“出院／整理”但缺少实际出院日期，显示为“待确认出院”，可补录而不误判为已出院。
- 新增六位完全脱敏虚拟患者的端到端验收测试，并纳入发布前硬性检查；覆盖普通、国疗、日间患者及建档、流程、任务、引流、出院、归档、撤回、回收站与备份恢复。
- 新增 50 位完全脱敏虚拟患者大型基准集（普通 25、国疗 15、日间 10），覆盖 7 个科室及在院、出院待归档、已归档状态，作为大型改动的发布前硬性回归测试。
