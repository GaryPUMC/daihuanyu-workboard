# 1.2.5 本地发布说明

## 本次调整

- 新增“科室管理”页，科室与病房通过同一页选项卡维护；两者均支持调整显示顺序。
- 支持归档和恢复科室，避免不再使用的科室占用日常选项；归档时保留患者、病房与本地历史资料。
- 移除科室前检查在院、归档和回收站记录；存在关联资料时必须二次确认，才会永久删除该科室、病房配置及关联患者资料。
- 存储层强制至少保留一个在用科室。
