# 1.2.1 本地发布准备

状态：本地源码包已准备，尚未上传或发布。

## 主要变更

- 新增共享 `validatePatientDraft`，由结构化导入、手工新增、患者详情编辑及数据层新增/批量新增/更新共同调用。
- 明确区分“待入院”和“已入院”：待入院可不填床位；已入院必须填写床位，且入院日期不得晚于当天。
- 未知患者类型和入院状态保持为空并要求人工选择，不再自动填写“普通”或从日期猜测状态。
- 普通／日间患者缺少科室时使用当前工作科室；国疗患者缺少科室时必须人工选择。
- 多病房科室中，日间患者仅在唯一“日间”病房时默认，普通患者仅在唯一“普通”病房时默认；国疗或无法唯一匹配时人工选择。
- 导入候选修改由底部弹层改为独立完整页面，避免键盘及弹层遮挡；增加入院状态、清除可选日期和逐字段错误提示。
- 手工新增、患者列表编辑、详情编辑和历史待核实资料统一显示红色高亮与“资料待补全”提示。
- 数据 schema 升级至 11；旧数据按既有日期事实迁移入院状态，并对缺日期、已入院但无床位等记录标记人工复核。
