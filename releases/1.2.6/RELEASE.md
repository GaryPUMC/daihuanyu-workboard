# 1.2.6 本地发布说明

## 本次调整

- 病历整理页由宽表格改为待办优先紧凑列表，主列表直接显示患者、全部未写节点及最近下次日期，不再隐藏为“还有 X 项”，也不需要横向滚动。
- 移除功能重复的“登记已写日期”入口；每个未写节点本身即可直接标记完成。
- 患者卡片改为上下两层并允许节点自然换行，列表视窗自动占满页面剩余高度，避免固定高度在不同尺寸窗口中留白或溢出。
- 点击患者展开完整纵向时间线，节点按日期由新到旧排列；POD 与出院窗口重合时只显示一次，未来节点仅保留最近一次。
- 取消按逾期程度的动态排序，改为按病房配置顺序、床位号和姓名稳定排列；点击完成或撤销后患者不再跳位。
- “仅看未写”仅展示在院待处理患者，不再与“出院待补”重复；顶部统计与当前视图保持一致。
- 完成最后一项后短暂保留该患者，便于立即撤销。
- 点击状态写入期间保持操作锁，并增加按压反馈，减少快速连点造成的误触感。
